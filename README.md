**AEOSUB Car Specs Printer** bridges this critical workflow gap for global traders. ## 📖 中文使用说明

1. **打开目标页面**：先打开汽车之家（autohome.com.cn）某款具体车型的“参数配置”页面；
2. **筛选对比**：在原网页中添加或减少需要对比的车型配置；
3. **一键抓取**：点击浏览器右上角扩展栏中的插件图标；
4. **预览与编辑**：系统自动开启新标签页，呈现净化后的排版参数表，可进行白标定制与导出。

## ✨ 核心功能

### 1. 清洗与多渠道导出
- 移除网页广告、导航栏与干扰元素，重构为整洁专业的版式。
- 支持插入车辆图片、公司 Logo、Slogan 及销售人员联系信息的白标配置。
- 支持一键导出高清长图、原生 PDF 打印，或直接复制纯净 HTML 代码以供 B2B 独立站使用。

### 2. FOB/CIF 报价计算器 (仅内部可见)
- 内置实时汇率接口（支持 USD/EUR 自动换算）。
- 支持录入指导价、加装配置、国内物流、港杂费、退税率等明细。
- 实时自动测算单车 FOB / CIF 出口总价与毛利区间。

### 3. 现车库存管理 (仅内部可见)
- 智能识别车辆内饰与外观颜色，一键生成库存勾选表，方便外贸销售快速录入现车数量与状态。

### 4. 本地化与隐私安全
- 配置与模板参数持久化保存在浏览器本地。
- 所有数据提取与运算均在客户端沙箱内完成，不采集任何用户浏览隐私。
