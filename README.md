# AEOSUB Car Specs Printer 🚗

【专为汽车出口贸易从业者打造的效率工具】
一键抓取、净化并生成高质量的汽车配置参数表，内置出口报价计算器与库存管理模块。

## 📖 使用说明

1. **打开目标页面**：请务必先打开汽车之家（autohome.com.cn）某款具体车型的“参数配置”页面；
2. **筛选打印**：可在原网页选择添加或减少需要对比的车型配置表；
3. **一键抓取**：点击浏览器右上角工具栏中的插件图标；
4. **预览与编辑**：系统将自动开启一个新标签页，为您呈现净化后的参数表。

## ✨ 核心功能

### 1. 清洗与多渠道导出
- 移除网页广告、导航栏和无用干扰元素，重构为清晰专业的版式。
- 支持车辆图片插入、公司Logo、Slogan、销售人员信息的自定义白标配置。
- 支持保存为高清长图、原生 PDF 打印，或复制纯净 HTML 代码。

### 2. 报价计算器 (仅内部可见)
- 内置 API 实时获取汇率（支持 USD/EUR 换算）。
- 支持录入指导价、加配、物流、港杂、退税等费用。
- 实时计算单车 FOB / CIF 出口总价及毛利。

### 3. 现车库存管理 (仅内部可见)
- 智能识别车辆内饰/外观颜色，一键生成库存选项表，方便销售快速勾选现车颜色并录入数量。

### 4. 个性化记忆
- 自动保存您的自定义白标设置和计算器参数，下次打开无需重复配置。

### 5. 安全与隐私
- 所有数据处理均在本地浏览器完成，不收集用户浏览记录，不上传任何服务器。

## 🌐 About this extension
A productivity tool exclusively designed for vehicle exporters. Works on Autohome (autohome.com.cn) car specification pages to extract and format car specification tables for clean printing and exporting. Features a built-in export cost calculator, real-time exchange rates, and stock color management.
